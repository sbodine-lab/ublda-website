# UBLDA workspace design direction

The authenticated workspace is a single operating surface for decisions, scheduling, the club calendar, project work, and the roster.

- `overview-concept.png` sets the desktop information hierarchy: persistent navigation, agenda, active work, and a short waiting-on-you list.
- `mobile-concept.png` sets the mobile interaction pattern: a compact header, left-aligned content, centered primary actions, and four persistent destinations.
- Production keeps the concept's white canvas, navy type, teal state color, thin dividers, and Plus Jakarta Sans typography.
- Production intentionally avoids the concept's fabricated metrics and sample people. Every rendered row comes from the signed-in workspace adapter.
